# Cloud Computing (AWS Services)

This repository contains practical screenshots and notes of various AWS cloud services, organized service-wise for easy learning and revision.

## 📂 Repository Structure

- AWS Lambda
- Amazon Rekognition
- Amazon SageMaker
- CloudWatch
- Cloud Alarm
- EC2 (Elastic Compute Cloud)
- S3 (Simple Storage Service)
- DynamoDB
- SNS (Simple Notification Service)
- SQS (Simple Queue Service)
- EC2 Connection using MobaXterm

## 🎯 Purpose
To document hands-on learning of AWS cloud services through screenshots and practical setups.

## 📝 Note
All folders contain step-by-step screenshots of AWS services implementation and usage.

## ☁️ Focus Areas
- Cloud Computing fundamentals
- AWS core services
- Monitoring & alerts (CloudWatch, SNS)
- Storage & databases (S3, DynamoDB)
- Compute & deployment (EC2, Lambda, SageMaker)
